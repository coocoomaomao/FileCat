# FileCat 文件整理猫

> 受够了“最终版2最终版”？让猫帮你收拾。

FileCat 是喵造实验室 009：一个 **local-first、安全优先** 的 Windows 文件整理工具。

## v0.2

v0.2 从“按扩展名整理”升级到“会看懂一点文件”。

### 智能用途分类

FileCat 会结合：

- 文件名
- 扩展名
- 修改时间
- 文件大小
- 少量可安全读取的纯文本内容

在本地给文件打上更接近用途的分类，例如：

- 学术科研
- 合同资料
- 公司财务
- 简历求职
- 会议演示
- 旅行资料
- 设计素材
- 照片截图
- 软件安装包
- 代码开发
- 视频素材
- 音频素材
- 压缩归档
- 表格数据
- 图片素材
- 普通文档

PDF / Office 等不适合直接读取正文的文件，在 v0.2 主要使用文件名和类型判断；FileCat 不会为了“聪明”而偷偷上传文件。

### 两种整理模式

**智能用途分类**
适合下载目录和桌面，优先按“这是什么东西”整理。

**传统文件类型**
继续保留 v0.1 的 PDF / 文档 / 表格 / 图片 / 视频等方式，最简单、最可预测。

### 清理观察

v0.2 会额外提示：

- 超过 1 年未修改的文件
- ≥ 500MB 的大文件
- 超过 90 天的安装包
- SHA-256 完全重复文件及理论重复空间
- “最终版 / final / v2 / 副本 / (2)”等疑似版本家族

**这些都是提示，不会自动删除。**

## 继承自 v0.1 的安全规则

- 只扫描用户主动选择的文件夹
- 只扫描当前层，不进入已有子文件夹
- 执行前完整预览
- 分类可取消勾选
- 整理到当前目录下的 `FileCat_整理/`
- 同名目标自动避让，不覆盖
- 一键撤销上一次整理
- 不永久删除任何文件
- 拒绝直接整理磁盘根目录、Windows、Program Files、ProgramData、AppData 等系统目录

## 隐私

v0.2 对可读取的文本类文件只读取前面少量内容做本地关键词判断，不上传 FileCat 服务器。

## 开发

```bash
npm install
npm test
npm run check
npm start
```

Windows 安装包：

```bash
npm run dist:win
```

## 设计原则

> AI 可以建议，最终移动权永远在人。

FileCat 宁愿少猜一点，也不在没有预览和撤销的情况下擅自整理你的电脑。
